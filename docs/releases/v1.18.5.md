# Rodin Essential v1.18.5 — Aurora

A deeper level of control, with a more responsive and consistent interface.

## Per-App Controls

- Added individual touch response, refresh rate, CPU and GPU settings for each app.
- Set independent CPU cores, cluster frequency ranges and governors per app.
- Choose supported 60/90/120 Hz refresh modes or OEM Adaptive.
- Selected overrides take priority while the app is in the foreground. Other controls continue following your global settings.
- Leaving the app or disabling Per-App Controls restores your previous global/ROM settings.
- Profiles remain saved across reboots and work without keeping Rodin Essential open.
- Per-App Controls is off by default; configure profiles before enabling them.
- Search installed apps using their actual names and icons. System apps are hidden by default and can be shown when needed.
- Reset an individual profile or clear all profiles from the section.

## Memory DVFS & UFS

- Added a dedicated hub for LPDDR5X Memory DVFS and UFS 4.0 controls.
- Set dynamic frequency ranges or equal minimum/maximum requests with Exact Lock.
- View current driver readings, active limits and your selected targets separately.
- Select frequencies supported by the device's drivers, with haptic slider feedback.
- Restore the original settings using OEM Reset.
- These are session controls: closing the app keeps them active; rebooting or restarting the daemon restores the original settings.

## Bypass Charging Tile

- Added a Bypass Charging tile to Quick Settings / Control Center.
- Toggle bypass without opening Rodin Essential.
- Long-press the tile to open Charging Control directly.
- Added a matching bypass icon and on/off state feedback.

## Interface & Interaction

- Refined Home and Control Hubs with clearer live information and a more consistent layout.
- Added rotating, colour-accented headlines to the Control Hubs banner.
- Added connected page transitions and predictive Back previews on supported Android versions.
- Added touch-following lighting, spring press feedback and more consistent haptics.
- Improved scrolling, page-opening and Back transitions, including gesture cancellation.
- Improved floating-dock dragging and tab switching, with clearer selection feedback.
- Refined glass headers and improved card outlines and dividers in light mode.
- Unified slider value bubbles across Dynamic Range and Exact Lock controls.
- Improved text wrapping and spacing across CPU, display, resolution, ZRAM, Support and app-control screens.
- Improved clearance between floating feedback cards, the dock, navigation bar and keyboard.

## Fixes & Changes

- Improved CPU core changes when the driver temporarily reports busy.
- Improved app/backend communication so control requests do not block interface interaction.
- Improved rendering when Android recreates the app window or the app returns from the background.
- Removed Double Tap to Wake from Rodin Essential; use your ROM's setting instead.

## Downloads

- **Rodin-Essential-KernelSU-Next-Magisk-v1.18.5.zip** — install through KernelSU Next or Magisk while Android is running, then reboot.
- **Rodin-Essential-ROM-Integration-v1.18.5.zip** — for ROM maintainers integrating Rodin Essential into extracted ROM images. Not flashable; follow the included `FULL-GUIDE.md`.

## ROM Maintainers

- Updated AOSP integration and the unpacked-ROM package for v1.18.5.
- Added the charging directory permissions needed to address blank battery readings and unavailable bypass detection on affected ROM integrations.
- Included Per-App Controls and Memory DVFS/UFS policy additions.
- Preserved the existing RAM devfreq parent label and MediaTek PowerHAL access.
- The ROM integration ZIP contains only Rodin Essential payloads and policy additions. Merge them with your own target ROM's policy using the included guide and tool.
- Update the app, daemon and policy together. Correct ROM integration works without a root manager or an app root prompt.
- Existing ROM-native installations must retain the same APK signing identity. The module can update a signature-compatible ROM-native installation.

Bypass charging requires a compatible kernel interface. Refresh rates and subsystem frequency choices depend on the modes exposed by your device's drivers.
