# Rodin Essential v1.18.4

Application and module version: **1.18.4 / 11804**. Daemon IPC protocol: **13.6**.
Both packages contain identical application and native runtime payloads.

## Changelog

- Added kernel-supported bypass charging with Immediate and 20/40/80/90%
  thresholds, background persistence and measured status reporting.
- Disabled competing charging-profile controls while bypass is enabled.
- Added whole-app hardware-control pause and reset, with redesigned confirmation
  dialogs and haptics.
- Added OEM Control defaults for touch response and display colour/temperature;
  the ROM retains ownership until the user selects an override.
- Serialized touch ownership changes with boot/wake restoration to prevent an
  older queued request from restoring a profile after OEM Control is selected.
- Retained bypass confirmation across page changes without rewriting an
  unchanged kernel request; background observation is independent of the app.
- Refined Home, Control Hubs, Support, charging cards, text wrapping, dock
  clearance and the bypass-threshold slider.
- Updated System Colors for Android-version-specific Monet fields, wallpaper
  restoration, bounded verification and rollback on unsupported implementations.
- Added the stock-EEA unpacked-ROM kit, porter guide, metadata and scoped policy.
- Updated AOSP integration guidance, application MCS labeling, certificate-bound
  IPC and the explicit platform-policy helper for native touch timing.
- Added one-time signing migration for user-installed module applications while
  retaining daemon hardware selections.

## Choose the correct ZIP

- **Rodin-Essential-KernelSU-Next-Magisk-v1.18.4.zip**: install from KernelSU
  Next or Magisk while Android is running, then reboot. Includes the app and
  authenticated hardware daemon. The Android app itself does not run as root.
- **Rodin-Essential-ROM-Integration-v1.18.4.zip**: integration package for extracted Rodin EEA
  OS3.0.302.0.WOJEUXM Android 16 images. **Do not flash this ZIP.** Follow its
  `FULL-GUIDE.md`, including exact ODM cache removal, metadata merge and image
  rebuild. Its full stock policy must not replace a different ROM's policy.

AOSP source-build integration is documented in
[ROM_INTEGRATION.md](https://github.com/NEESCHAL-3/Rodin-Essential/blob/main/docs/ROM_INTEGRATION.md).
The correctly integrated native service needs no root manager at runtime.

## Updating an existing installation

The signing identity changed in v1.18.4. For an ordinary user-installed APK,
the module attempts a normal update first. A signature mismatch triggers a
one-time application reinstall: daemon profiles remain saved, but app-local
appearance/preferences reset. Subsequent same-key updates retain application data.

A ROM-native installation can use the module as an update layer **only if its
APK has the same signing identity**. The module shares native daemon state and
restores the native APK/service when removed. Older or maintainer-signed native
APKs with a different identity require a ROM update; this module does not bypass
Android signature checks or delete a system app.
